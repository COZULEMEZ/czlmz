## 🚀 GitHub & Vercel Deployment Guide

### 1. GitHub'a Yükleme (Adım Adım)
Eğer GitHub Desktop veya VS Code kullanıyorsan klasörü doğrudan açıp commit edebilirsin. Ya da terminalden:

`ash
git init
git add .
git commit -m feat: official cozulemez.com release with opium aesthetic & massive SEO
git branch -M main
git remote add origin https://github.com/KULLANICI_ADIN/cozulemez.com.git
git push -u origin main
`

### 2. Vercel'e Bağlama ve Yayınlama (1 Tık)
1. [vercel.com](https://vercel.com) adresine git ve giriş yap.
2. **Add New...** -> **Project** butonuna tıkla.
3. GitHub hesabındaki cozulemez.com reposunu seç ve **Import** de.
4. **Framework Preset**: Other olarak kalacak (herhangi bir build command gerekmez).
5. **Deploy** butonuna bas. Siten 10 saniye içinde canlıya geçecek!

### 3. Özel Domain Ekleme (cozulemez.com)
1. Vercel proje panelinde **Settings** -> **Domains** sekmesine git.
2. cozulemez.com ve www.cozulemez.com yazıp **Add** de.
3. Domain sağlayıcındaki DNS yönetimine Vercel'in verdiği A kaydını (76.76.21.21) ekle.
